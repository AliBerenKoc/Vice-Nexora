# Vice Nexora

Vice Nexora is an unofficial browser-based project built upon open-source work related to running Grand Theft Auto: Vice City through WebAssembly.

## About

The project provides a web interface for a browser-based game engine using modern web technologies.

This project is independently maintained and is not affiliated with, endorsed by, or sponsored by Rockstar Games or Take-Two Interactive.

Vice Nexora acknowledges the developers and open-source projects that inspired or contributed to the underlying technology:

## Technologies

The project uses web technologies such as JavaScript, Vite, and WebAssembly. Browser storage and other browser APIs may be used by supported components.
