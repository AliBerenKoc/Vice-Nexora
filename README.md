# Vice Nexora

Vice Nexora is an unofficial browser-based project built using open-source software related to running Grand Theft Auto: Vice City through WebAssembly.

## About

This project adapts and builds upon existing open-source work to provide a browser-based interface for the game engine.

The project is independently maintained and is not affiliated with, endorsed by, or sponsored by Rockstar Games or Take-Two Interactive.

This project builds upon work from the following projects and contributors:

## Technologies

The project uses web technologies including JavaScript, Vite, and WebAssembly. Depending on the component, it may also use browser storage, Web Workers, and Service Workers.
